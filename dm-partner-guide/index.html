크롬 확장프로그램 설치

설치한 다음,
‘옵션’을 열어주세요.

PC 크롬에서 설치하고,
아래 순서로 설정 화면까지 이동합니다.

  1. Chrome 웹 스토어에서 설치

    아래 버튼 → ‘Chrome에 추가’
    → ‘확장 프로그램 추가’를 선택합니다.

  2. 확장프로그램의 ‘세부정보’ 열기

    크롬 주소창에 chrome://extensions 입력
    → IG Lead Saver의 ‘세부정보’를 누릅니다.

  3. 아래로 내려 ‘확장 프로그램 옵션’ 클릭

    오른쪽 화면에서 빨간 테두리로 표시한 항목입니다.
    클릭하면 IG Lead Saver 설정 화면이 열립니다.

주소와 이름을 넣고,
캠페인을 선택해요.

Apps Script 웹앱 URL웹에서 URL 복사하기 ↗

복사한 주소를 오른쪽 화면의 URL 칸에 붙여넣으세요.

  1. URL 붙여넣기 + 본인 이름 입력

    ‘연결 테스트’를 눌러 ‘연결됨’ 표시를 확인합니다.

  2. 캠페인 목록 새로고침 → 탭 선택

    ‘진행 중인 캠페인’ 오른쪽 ↻ 버튼을 누른 뒤,
    단톡에서 안내받은 캠페인 탭을 선택합니다.

  3. 맨 아래 ‘설정 저장’ → 저장목록 불러오기

    ‘기본 상태’는 연락전으로 두고, 페이지 맨 아래에서 저장합니다.
    위로 돌아와 ‘시트에서 저장목록 불러오기’를 누른 뒤
    인스타그램 탭을 새로고침하면 준비 완료입니다.
