# 인플루언서 모집 파트너 안내

신규 파트너에게 보내는 SIRIAI DM 모집 업무 가이드. 기존 회사 소개서의 색상과 타이포를 기준으로 제작한 9장 정적 안내 페이지다.

- PC: 목차와 방향키로 이동
- 모바일: 세로 스크롤, 목차 이동
- PDF: guide.pdf
- 확장프로그램 설치: [Chrome 웹 스토어](https://chromewebstore.google.com/detail/ghakpcjppjjlcmfcalfklciejlbilonn)
- 프로필 자료: downloads/profile-assets.zip

내용 수정은 index.html, 스타일은 style.css, 탐색 기능은 app.js에서 관리한다. guide.pdf는 같은 HTML을 1280×720 인쇄 크기로 렌더링한 파일이다. 모집 조건과 연결 주소는 캠페인별로 별도 전달한다. 시트 화면 예시는 가상의 계정 정보로 구성했다.
