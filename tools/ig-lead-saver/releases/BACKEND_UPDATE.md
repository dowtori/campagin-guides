# Apps Script 백엔드 업데이트 · 운영자용

이 파일은 스토어에 올리는 확장 패키지와 별개입니다. 기존 관리자가 기존 시트에 연결된 Apps Script를 업데이트합니다.

1. 현재 배포의 코드·버전과 /exec URL을 기록합니다.
2. 기존 Apps Script 프로젝트에서 Code.gs를 첨부한 내용으로 교체해 저장합니다.
3. 배포 → 배포 관리 → 기존 배포 편집 → 새 버전을 선택해 업데이트합니다. 실행 계정과 기존 접근 설정을 유지합니다.
4. /exec URL이 기존과 같은지 확인합니다. 확장 사용자들의 연결 주소를 바꿀 필요가 없게 합니다.
5. 기존 확장 1.4로 연결 테스트·이력 읽기·테스트 시트 1건 저장·중복을 확인합니다. 이어서 확장 1.5에서도 확인합니다.

변경: list/ping/listSheets를 저장 잠금 밖에서 읽도록 분리했습니다. append/createSheet/importHistory는 기존 잠금을 사용하며 저장 후 flush하고 해제합니다. 기존 시트 열과 상태·정산 데이터는 초기화하지 않습니다.

현재 포함된 자동 검증은 모의 Apps Script 객체를 사용합니다. 이 ZIP을 만드는 작업에서 운영 배포를 수정하거나 실제 시트에 행을 기록하지 않았습니다.
