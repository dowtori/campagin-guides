# Siriai Recruiter Island v6.11

폰의 큰 아이콘 메뉴로 챕터를 고르면 해당 장소로 이동해 시작합니다. 완료한 챕터는 다시 열 수 있고, 중간 작업은 이어갑니다. 기본 과정을 마칠 때마다 따봉이 성장하며, 선택 심화 미니게임 세 가지를 모두 마치면 왕따봉이 해금됩니다.

블록 계단형 산과 바늘 줄기를 교체하고 실제 태양 방향에 맞춰 노을 조명을 설정했습니다. 편집 화면에서도 바다가 보이도록 수면을 저장하고, 플레이 중에는 실제 Terrain 물로 전환합니다. 업무 내용은 실제 운영 기록과 대조해 캠페인별 접수 방식·최종 선정 구분·완료 공유를 반영했습니다.

현재 재제작본은 **[v6.11 프로젝트](v6/README.md)**입니다. 준비 → 크리에이터 → DM 데스크 세 곳을 방문하면 첫 캠페인이 끝납니다. 프로필·연결은 예시를 하나씩 채운 뒤 실제 준비 여부를 선택합니다. 기본 완료 후 인플루언서 선별은 30초 벽면 선택, 고료·추가 조건 문의는 시간제한 없는 NPC 답변 선택으로 연습합니다.
