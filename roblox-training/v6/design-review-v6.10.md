# v6.10 — 자연환경 수정 전 판정 기준 (2026-10-26)

## 사용자 사진에서 확인한 실패
- 산 능선이 16스터드 블록 계단이다. 현재 저장된 지형은 큰 블록이며 실행 시 Terrain이 완성되어야 숨는다. 사진이 생성 도중인지 실패 뒤인지 아직 확인되지 않았다.
- 폭 .045짜리 줄기와 .18짜리 잎은 플레이어 거리에서 선으로만 보인다. 개수만 늘리는 것으로 해결하지 않는다.
- 붉은 해는 고정 장식이고 Lighting의 태양 방향과 무관하다. 기본 Soft 조명, 약한 반사와 대기로는 의도한 해 질 녘이 전달되지 않는다.
- 웹의 별도 물 셰이더와 매끄러운 지형을 실제 Roblox 품질 검증으로 취급하면 안 된다.

## 구현 전에 고정한 기준
1. 편집용 육지에도 수평 계단 단면이 없어야 한다. 이웃 삼각면은 같은 높이 샘플을 공유한다. 플레이의 네이티브 Terrain은 부분 점유율로 만들고, 수면은 산 생성보다 먼저 전환한다. 산 생성 실패가 실제 수면을 덮지 않아야 한다.
2. 기존 바늘형 줄기는 제거한다. CC0 원본의 넓은 잎을 겹쳐 전경 군락을 구성한다. 동선 옆은 낮고 뒤쪽은 높다. 대표 군락 중심의 80% 이상은 이웃 군락 잎 폭과 겹친다. 교육 통로·상호작용 시야는 유지한다.
3. 태양은 엔진 GetSunDirection과 같은 방향에 있어야 한다. Realistic 조명, 따뜻한 직사광, 보랏빛 주변광, 대기 산란, SunRays와 수면 반사를 한 구성으로 저장한다. 태양만 붉게 유지한다.
4. 환경 수정으로 기본 교육, 폰, 보상, 선택 심화의 동작을 바꾸지 않는다. 133스터드 필수 동선과 물 복귀 검사를 통과해야 한다.
5. 판정은 분리한다. 저장 파일·형상·실제 내보낸 스크립트 검증은 여기서 수행한다. Roblox 엔진의 최종 색·반사·성능은 Studio가 없어 미확인으로 남긴다. 웹 렌더링을 엔진 스크린샷처럼 제시하지 않는다.

## 채택한 자료와 범위
- Roblox 공식 outdoor lighting 예제: https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/enhance-outdoor-environments — Realistic, 실제 태양, 주변광, 대기와 반사 설정 방식.
- Roblox Duvall Drive landscaping: https://create.roblox.com/store/asset/10840661513/Landscaping-Pack-Duvall-Drive — 낮은 식생·군락·수관의 층을 구성하는 방식만 참고. 해당 자산은 재배포하지 않는다.
- Grass Engine 제작자: https://devforum.roblox.com/t/grass-engine-v102-a-free-interactive-foliage-system/3070440 — 기본 Terrain 잔디와 가까운 군락, 거리별 움직임을 분리하는 방식. 소스는 복사하지 않는다.
- Kenney Nature Kit: https://kenney.nl/assets/nature-kit — CC0 grass_leafs 원본 사용. 원본 형상을 보존하고 색·크기·배치만 조절한다.
- WindShake: https://github.com/boatbomber/WindShake — 이미 포함한 MIT 원본 유지. 군락 루트만 바람에 반응시키고 하위 면은 함께 이동한다.
- 태양 방향: https://devforum.roblox.com/t/help-3d-sun-moon/3274549 — 카메라 기준 GetSunDirection으로 태양 위치를 맞추는 구현 원리. 런타임은 공식 엔진 API 사용.

## 결과
- 저장 표면 1,960개 표본 꼭짓점이 원본 높이와 일치하며, 큰 블록 기둥은 0개다. 바다 준비 후 산 생성 오류를 주입해도 실제 수면이 노출되는 것을 확인했다.
- 최종 모델은 Kenney `grass` 원본으로 조정했다. 넓은 `grass_leafs`는 형상 미리보기에서 종이 조각처럼 보여 채택하지 않았다. 굽은 잎 11개의 원본 자세를 유지하고 폭만 45%로 조정했다. 평면 삼각형 두 장을 하나의 직사각형으로 합쳐 원본 윤곽을 보존했다.
- 1,024군락의 99.7%가 이웃 군락의 폭 범위와 겹친다. 저장된 잎의 경계가 변환한 원본 정점과 0.02스터드 이내로 일치한다. 길 가장자리 키는 약 1.3–1.8, 안쪽은 2.3–3.3스터드다. 기본 Terrain 잔디가 하층을 담당한다.
- 원본 WindShake는 수정하지 않았다. 군락당 루트 하나를 85스터드 범위에서 최대 30Hz로 움직이고, 모든 면에 같은 변환을 적용한다. 납작한 구름 덩어리는 제거했다.
- 내보낸 rbxlx에서 Realistic 조명·반사·잔디·SunRays·색 보정의 저장을 확인했다. 태양 장식은 엔진 방향에 연결한다. 저장 시 태양 고도는 약 6.1도다.
- 물 서버 143검사, 기존 전체 교육·폰·심화·보상 회귀 검사, 133스터드 필수 동선 검사를 통과했다. 웹에서 저장된 산과 식생 형상을 직접 확인했다.
- 총 68,911개 네이티브 부품이다. 기존보다 인스턴스 수가 늘었으며 실제 모바일 성능은 미측정이다. 모델을 무근거로 고성능이라고 평가하지 않는다.
- **최종 시각 승인 보류:** Studio가 없어 실제 엔진의 노을 색·수면 반사·초기 로드·프레임 속도를 확인하지 못했다. 웹 셰이더는 이 항목들의 증거로 사용하지 않았다. 코드·형상 기준 충족과 실제 엔진 품질 승인은 구분한다.
