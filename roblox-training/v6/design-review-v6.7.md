# v6.7 따봉 개선 — 수정 전 판정 기준

기준일: 2026-10-25. 비교 버전: v6.6 / 06e5aad.
사용자가 v6.6의 네 손가락 묘사와 유아적인 조형을 거절했다. 이전 T1/T2 통과는 기능/식별성 평가였고, 원하는 감도의 합격을 뜻하지 않는다.

## 레퍼런스에서 채택하는 것
- [Slap Battles](https://www.roblox.com/games/6403373529/Slap-Battles): 공식 경험 페이지와 실제 장갑 진열 스크린샷을 확인. 얼굴 없는 큰 손, 기본형→금색/성장 변형의 직접적인 보상 표현을 참고.
- [Comically Large Spoon](https://www.roblox.com/catalog/12090385963/Comically-Large-Spoon-Hand-Item): Roblox CDN 제품 이미지를 확인. 사물을 꾸미기보다 크기/비율 하나를 과장하는 방향을 참고.
- 스크린샷 출처: [기본 장갑](https://progameguides.com/roblox/how-to-get-the-really-badge-in-slap-battles-roblox/), [Golden/Thick 진열](https://progameguides.com/roblox/how-to-get-the-touch-of-midas-badge-in-slap-battles-roblox/).
- 직접 게임을 플레이한 것은 아니다. 레퍼런스 모델·텍스처·소리·이미지는 배포물에 넣지 않는다. 손 실루엣은 직접 설계한다.

### 검수 중 수정
- 처음의 수직 엄지를 바깥으로 기울였다. 네 손가락 묘사를 다시 넣지 않았다.
- 받침도 함께 커지던 구조를 고정 받침으로 바꾸고, 손 하단을 받침 상단에 고정했다. 큰 손과 작은 받침의 크기 차이를 유머로 사용한다.
- 기존 나루터 카메라는 더 커진 왕따봉의 상단이 잘려 뒤로 옮겼다. 이전 카메라는 `pierClose`로 남겼다. 카메라 이동 자체를 조형 개선 근거로 세지 않았다.
- 자연환경·교육·동선은 비교 시 고정. 생성 맵에서 따봉과 버전 명패를 제외한 모든 노드가 v6.6과 동일함을 검사했다.

### 재현 및 범위
- 공개 미리보기에서 `?view=pier&thumb=0`, `?view=pier&thumb=7`, `?view=pier&thumb=10`은 같은 카메라다.
- `?view=thumbPortrait&thumb=10`은 보상창과 같은 카메라 방향이며, 작은 160×190 검수 화면도 따로 확인했다.
- `tests/reward-geometry.py`: 실제 쐐기 정점 기준 바닥 접지·높이·나루터 범위·보상 카메라 검사 통과.
- `tests/run.py`: Rojo에서 내보낸 보상/챕터/폰/심화/해안/물가 복귀 콜백 검사 통과. 보상에는 새 실루엣의 11단계 전환을 포함한다.
- 실제 Roblox Studio가 설치되어 있지 않아 엔진 렌더링·재질·물리·멀티플레이 세션은 확인하지 못했다. 이번 결과는 제거/크기/동선/표시 기능을 검증한 조형 수정본이며, 사용자의 미감 평가를 대신하지 않는다.
