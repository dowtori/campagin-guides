# Siriai Recruiter Island v6.8

인플루언서 모집 업무를 NPC 의뢰와 도구 사용으로 익히는 Roblox 검토용 맵입니다. 이전 버전의 퀴즈 엔진·부스 구조와 독립된 프로젝트로 다시 만들었습니다.

1. `downloads/SIRIAI_Recruiter_Island_v6_8.rbxl`을 Roblox Studio에서 엽니다.
2. **플레이**를 누르고 시작 부두 앞쪽의 매니저에게 다가갑니다.
3. **E / 화면 터치**로 첫 캠페인을 받습니다. 폰 버튼·P 키·도구 장착으로 리크루터 폰을 엽니다. 들고 있는 동안 좌클릭은 폰을 열지 않습니다.
4. 준비 테라스 → 크리에이터 정원 → DM 데스크 순서로 길을 따라 이동합니다. 같은 장소의 작업은 창에서 바로 이어집니다.
5. 폰에서 **챕터 버튼**을 누르면 그 장소로 이동해 바로 시작합니다. **이어서 하기**는 현재 작업을 엽니다. 완료 표시는 실제로 마친 챕터에만 생기고, 완료한 챕터도 다시 열 수 있습니다. 모든 챕터를 마치면 바다로 이동하거나 선택 부록을 볼 수 있습니다.
6. 작업 중에는 폰·다른 상호작용이 화면을 덮지 않습니다. 연결·발송·응대의 중간 단계는 창을 닫아도 이어집니다. 재접속하면 새 연습을 시작합니다.

웹 링크는 공간 미리보기와 파일 배포용입니다. 본인 Roblox 계정에서 경험으로 게시한 뒤 생성되는 링크로 접속할 수 있습니다.

## 업무와 게임 구조

필수 방문지는 세 곳이며 되돌아가는 구간이 없습니다.

- **준비 테라스:** 캠페인 기준을 받고, 버튼을 눌러 프로필·연결 예시를 채웁니다. 완성된 예시로 이해를 확인한 뒤 실제 준비 여부를 선택합니다. 한 자리에서 이어집니다.
- **크리에이터 정원:** 콘텐츠·팔로워·기존 접촉 이력을 살펴보고 적합한 계정을 저장합니다.
- **DM 데스크:** 제공 문구로 DM을 보내고 상태를 기록합니다. 일반적인 지원 완료 회신에 짧게 답한 뒤, 이후 도착한 최종 선정 안내와 정산 예시를 확인하면 기본 과정이 끝납니다.

기본 과정을 마치면 폰의 **심화 도전**에서 인플루언서 선별·고료 조정·모르는 조건 문의를 연습할 수 있습니다. 기본 수료와 별개인 선택 과정입니다. ‘부록’은 답변 참고용으로도 남겨두었습니다. 지원 완료를 최종 선정으로 처리하지 않습니다.

실제 DM·시트·단톡으로 발송하는 기능은 없습니다. 게임 안의 사람과 캠페인은 연습 사례입니다. 실제 조건·양식·지급일은 별도 업무 안내와 계약서를 따릅니다. 실제 발송 계정이나 시트로 연결하지 않습니다.

## v6.8: 큰 챕터 메뉴와 완료 표시

- [사전 기준·레퍼런스·검수 결과](design-review-v6.8.md).
- 번호와 제목을 하나로 묶고 22–26px로 키웠습니다. 메뉴 이미지는 같은 선·색상의 네이티브 아이콘으로 통일했습니다.
- 완료한 버튼에 44–54px ‘완료’ 도장을 표시합니다. 버튼을 누르면 다시 들어갈 수 있습니다.
- 게임 점수, 도착·다음 단계 중복 알림, 반복 안내를 제거했습니다. 실제 단가·조건·오류 안내는 유지했습니다.

## v6.7: 얼굴 없는 거대 따봉

- [사전 기준·레퍼런스·검수 결과](design-review-v6.7.md).
- 네 손가락 마디, 손톱, 얼굴, 옷, 왕관을 모두 제거했습니다. 손목·주먹 덩어리·엄지만 남은 직접 제작 실루엣입니다.
- 동일한 작은 받침 위에서 손만 11단계로 커지고 엄지 비율이 과장됩니다. 기본 7개 완료 후 황금색, 심화 3개 완료 후 왕따봉입니다.
- 레퍼런스의 모델이나 이미지는 사용하지 않았습니다. 모든 조형은 네이티브 Roblox 솔리드입니다.
- 아래 v6.6/v6.5의 표정·의상 설명은 당시 변경 기록이며 현재 조형에는 없습니다.

## v6.6: 개선 기준을 먼저 고정한 시각 정리

- [사전 판정 기준과 결과](design-review-v6.6.md)를 기준으로 점검했습니다.
- 따봉은 대표 장식이 교체됩니다. 왕따봉은 웃는 표정·망토·왕관만 남기고, 엄지가 왕관보다 높게 보입니다.
- 심화 방은 92×68 → 56×36스터드, 선택 벽까지 26.6스터드. 낮은 중앙 조작대와 동등한 3개 선택 영역을 둡니다.
- 조건·선택·조작대의 물리 비율을 SurfaceGui 캔버스와 일치시켰습니다. 선택지 조건은 크게 세 줄로 분리했습니다.
- 나무는 Kenney oak 계열로 통일하고 수관/관목을 군락으로 배치했습니다. 갈대는 통통한 이삭 대신 가늘게 퍼지는 이삭, 구름은 겹친 덩어리로 바꿨습니다.
- 웹 미리보기는 공간/가독성 검수 도구이며 Roblox 엔진의 최종 조명·텍스트·터치·성능 검증을 대신하지 않습니다.

## v6.5: 따봉 성장과 맵 안의 심화 미니게임

- 기본 챕터를 처음 완료할 때마다 10점과 따봉 성장 1단계를 얻습니다. 아기 따봉 → 선글라스 → 웃는 얼굴 → 나비넥타이 → 망토 → 반짝임 → 황금 따봉으로 커집니다.
- 기본 7개 챕터 완료 후 폰에서 **심화 도전**을 누르면 도전 방으로 이동합니다.
- **인플루언서 선별:** 먼저 벽의 조건을 읽습니다. ‘시작’을 눌러야 30초가 시작됩니다. 벽면 세 후보 중 한 명을 터치하거나 가까이 가서 E로 선택합니다. 재도전 시 조건과 배치가 바뀝니다.
- **고료 조정 / 모르는 조건 문의:** 세 NPC의 답변 중 하나를 고릅니다. 시간제한이 없습니다.
- 각 심화 도전의 첫 성공은 100점입니다. 세 가지를 모두 성공하면 심화 보너스 300점, 총 370점과 **왕따봉**이 해금됩니다. 왕관·콧수염·망토를 갖춘 큰 조형물을 보러 바로 이동할 수 있습니다.
- 실패·시간 초과 후 벽면 또는 콘솔에서 **다시 도전**을 누르면 그 자리에서 다시 시작합니다. 조건을 읽는 동안에는 타이머가 없습니다.
- 방을 나가거나 다른 챕터로 이동하면 해당 시도만 취소합니다. 이미 획득한 보상은 현재 접속 세션 동안 유지됩니다.
- 따봉과 심화 화면은 개인 진행도에 따라 표시됩니다. 다른 플레이어의 답변이 내 화면이나 점수를 바꾸지 않습니다.
- 게임 점수는 정산 예시 2,300원과 별개입니다. 챕터 재학습이나 심화 재도전으로 점수를 중복 적립하지 않습니다. 재접속 시 새 연습을 시작합니다.

서버의 시간을 기준으로 30초를 판정합니다. 화면의 카운트다운이 늦어져도 종료된 시도는 점수를 주지 않습니다. 문제·선택지는 PlayerGui의 SurfaceGui가 실제 벽면에 붙는 방식이며, ScreenGui 팝업으로 출제하지 않습니다.

## v6.4: 그림 메뉴로 챕터 선택

[Conveyor Sushi Restaurant](https://www.roblox.com/games/11848247239/Conveyor-Sushi-Restaurant)의 주문 메뉴에서 참고한 큰 그림 타일을 폰에 적용했습니다. 가로 화면은 첫 챕터를 넓게 놓은 7개 타일, 세로 화면은 2열 스크롤입니다. 그림을 누르면 선택한 작업 장소로 이동해 화면이 바로 열립니다. 현재 챕터와 완료 표시를 구분하고, 이어하기 버튼은 아래에 고정했습니다. 폰·작업 화면 사이의 좌클릭 충돌 방지도 유지합니다.

챕터 순서는 자유입니다. 건너뛴 챕터는 완료로 기록하지 않으며, 현재 챕터를 마치면 다음 미완료 챕터로 이어집니다. 마지막부터 시작하면 남은 앞쪽 챕터로 돌아갑니다. 후반 챕터는 해당 장면의 연습 기록을 제공하며, 그 입력을 실제로 완료한 앞 단계의 기록으로 만들지 않습니다. 재학습은 보수 예시를 중복 합산하지 않습니다. 아직 끝내지 않은 설정·발송 화면은 다른 챕터에 들렀다 와도 이어집니다.

설정 완료 화면의 반복 설명과 중복 카드, 발송 버튼과 같은 뜻의 안내, 폰의 중복 이동 버튼과 구현 설명을 제거했습니다. 설정 방법 이해 확인, 안내서로 설정 후 돌아오기, DM에 포함된 기본 고료, 지원·최종 선정 구분과 정산 기준은 남겼습니다.

참고 게임의 음식 이미지·로고·배경은 사용하지 않았습니다. 메뉴에는 시리아이 원본 자료와 이 맵의 크리에이터 이미지, 직접 만든 네이티브 UI 도형을 사용했습니다.

## v6.3: 채워서 이해하고 실제 설정으로

프로필은 로고 → 원본 게시물 6장 → 소개·링크가 채워집니다. 연결 화면은 확장프로그램 → 받은 주소·본인 이름 → 캠페인·저장 상태가 채워집니다. 매번 지금 할 행동 하나만 제시하며 순서를 맞히는 문제와 가짜 URL 입력·연결 테스트를 없앴습니다.

완성된 예시에서 **이해했어요**를 누르면 **지금 하기 / 이미 완료했습니다** 두 가지를 선택합니다. 지금 하기는 받은 안내서의 해당 부분에서 실제 설정을 마치고 돌아오는 안내입니다. 돌아와 **설정했습니다 · 계속**을 눌러야 다음 과정으로 진행합니다. 안내를 열기만 해서는 완료되지 않습니다. 이미 완료했다면 다시 설정하지 않고 다음으로 이어집니다. 실제 외부 계정·확장프로그램의 상태를 검증하지 않으며, 기록은 사용자의 완료 확인입니다.

실제 바로가기는 웹 배포 페이지와 메일에 제공합니다: [계정 세팅](https://campagin-guides-un3g.vercel.app/dm-partner-guide/#account) · [확장프로그램 설치·연결](https://campagin-guides-un3g.vercel.app/dm-partner-guide/#extension). Roblox 안에는 외부 URL이나 동작하지 않는 브라우저 열기 버튼을 넣지 않았습니다. [Roblox 공식 외부 링크 안내](https://en.help.roblox.com/hc/en-us/articles/360000910966-Social-Media-Links-for-Experiences-Communities)를 확인하고 사용자와 이 방식을 정했습니다.

설정 예시와 돌아오기 안내는 현재 플레이 세션에서 창을 닫았다 열어도 유지됩니다. 재접속 시 새 연습을 시작하는 기존 동작은 유지됩니다.

## v6.3.1: 나루터 조형물

나루터 끝의 평면 로고판을 제거하고, 길 옆에 둥근 따봉 조형물과 낮은 받침을 배치했습니다. 엄지·접힌 손가락·손목에 실제 두께가 있는 기본 입체로 직접 제작했습니다. 중앙 진입로와 물가 계단, 벤치 정면을 비워 두었습니다. 웹 미리보기의 **나루터** 시점에서 볼 수 있습니다.

## 지형과 물

실제 높이 데이터로 연결된 능선과 두 개의 원경 섬을 생성합니다. 해·산을 그려 놓은 이미지 벽은 없습니다. 붉은 태양은 별도의 구체이며 native Atmosphere·Clouds와 움직이는 입체 구름을 사용합니다.

수면 아래 실제 Terrain Water와 모래 해저를 채웁니다. 물가 계단에서 들어갈 수 있고 바깥은 수영할 깊이입니다. 지형 편집은 작은 구역으로 나눠 엔진 voxel 편집 한도보다 작게 처리합니다. 연속된 보조 해저와 낙하·범위 이탈 시 비치명적 복귀가 있습니다. 지형 API가 실패하면 지면 미리보기와 복귀 기능을 유지합니다.

## 자료와 라이선스

시리아이의 제공된 원본 로고, 프로필 게시물 6장과 설정 캡처를 포함했습니다. 브랜드 이미지를 임의로 생성하지 않았고 이미지 렌더링에 Pixelated 모드를 사용하지 않습니다. 가상 크리에이터 게시물 9장은 별도로 생성했으며 `assets/generation-prompt.json`에 생성 방식과 프롬프트를 남겼습니다.

Kenney Nature Kit CC0 모델은 실제 OBJ 정점·면을 native WedgePart로 가져옵니다. v6.1에서 정리한 둥근 활엽수 수관·낮은 식물·해안 바위로 종류를 정리하고, 수관이 겹치는 작은 숲과 갈대 군락으로 배치했습니다. 나무·풀·바위의 색을 해안 팔레트로 통일했고, 평지를 Grass 재질과 native 잔디로 변경했습니다. 바람은 MIT WindShake의 고정 커밋 소스입니다. 각 출처와 라이선스를 배포물에 포함했습니다. 인기 게임의 캐릭터·지형·음악·썸네일은 배포물에 포함하지 않았습니다.

## 빌드

Python과 Pillow, Rojo 7.7.1을 사용했습니다.

```sh
python build_images.py
python build_world.py
rojo build default.project.json -o downloads/SIRIAI_Recruiter_Island_v6_8.rbxl
rojo build default.project.json -o downloads/SIRIAI_Recruiter_Island_v6_8.rbxlx
python tests/run.py --luau /path/to/luau
python tests/geometry.py
python tests/route.py
python tests/reward-geometry.py
```

내보낸 파일의 실제 ModuleScript·Script 소스를 검증에 사용합니다. 클라이언트와 서버의 콜백을 데스크톱·터치 모드 어댑터에서 실행하고 근접 거리·요청 순서·중복 완료·기록을 검사합니다. 물 서버는 실제 소스의 API 정상·호환·실패 경로를 확인합니다.
